# Mindset Lab

Сайт публикуется штатной сборкой Jekyll в GitHub Pages из ветки `main`.

## Страницы

- `/` - существующая программа «Место в профессии и на рынке».
- `/programs/` - каталог программ.
- `/programs/professional-transition/` - первый драфт программы о профессиональном переходе.
- `/editor/` - вход и краткая инструкция для самостоятельного редактирования.

## Редактирование текста

Открыть [Pages CMS](https://app.pagescms.org/), войти через GitHub и выбрать этот репозиторий, ветку `main`. При первом входе потребуется разрешение GitHub на доступ Pages CMS к репозиторию.

В редакторе доступны «Профессиональный переход» и «Каталог программ». Заголовки, тексты, вопросы, ответы, цены и расписание представлены обычными полями. Длинные тексты редактируются визуально. После Save изменения сохраняются в GitHub и запускают автоматическую пересборку сайта.

Все тексты новой программы хранятся в `_data/professional_transition.json`, каталог в `_data/programs.json`. Схема визуального редактора находится в `.pages.yml`. Шаблон страницы `_includes/professional-transition.html` не содержит копий программного текста. Дизайн хранится отдельно в `assets/mindset-lab.css`.

Раздел с историей личного перехода автора намеренно оставлен пустым абзацем между переездом на Кипр и рассказом об Академии. Текст находится в процессе авторской редакции.

Новая программа помечена `seo.draft: true`, поэтому содержит `noindex,nofollow`. После завершения текста эту отметку можно снять в редакторе. Часовой пояс расписания пока не задан автором и не добавлен предположением.

## Локальная проверка

`python3 scripts/preview.py` формирует `.preview/` из тех же JSON и шаблонов. Это простой локальный рендер используемого подмножества Liquid, а производственную страницу собирает настоящий Jekyll в GitHub Pages.


## Оформление лендинга

В Pages CMS доступен раздел «Оформление лендинга»: цвета выбираются по названиям; размеры и расстояния вводятся в числовых полях; фоны разделов выбираются из трёх вариантов. Настройки хранятся в `_data/professional_transition_design.json` и применяются при сборке через `_includes/transition-design.html`. Кнопки используют исходный коралловый, две текстовые плашки используют отдельный мягкий персиковый.

В FAQ показываются все 6 авторских вопросов с исходными ответами. Не сокращать, не переписывать и не скрывать тексты без прямого указания автора.

Фотографии на первом экране и в блоке «Обо мне» заменяются в Pages CMS: «Профессиональный переход» → «Фотографии». Общие параметры под форматом редактируются в отдельном блоке «Общие параметры под форматом». Цвет персиковых акцентов и фон результатов доступны в «Оформление лендинга».
